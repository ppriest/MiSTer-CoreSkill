## Jobs and locks

### `cores_list`

*read-only*

Core repositories found under the cores directory (MISTER_CORES_DIR).

### `jobs_list`

*read-only*

Jobs from every session, newest first.

| Argument | Type | Default |
|---|---|---|
| `active_only` | boolean | `false` |
| `limit` | integer | `20` |

### `jobs_status`

*read-only*

A job's state, return code and log tail; waits up to wait_s for it to end. Ended jobs carry `result` (parsed timing, sim summary or capture manifest) where the kind has one.

| Argument | Type | Default |
|---|---|---|
| `job` | string | required |
| `wait_s` | integer | `0` |
| `log_lines` | integer | `20` |

### `jobs_log`

*read-only*

A job's log: the last `lines` lines, or the lines matching the regex `grep`.

| Argument | Type | Default |
|---|---|---|
| `job` | string | required |
| `grep` | string | `""` |
| `lines` | integer | `200` |

### `jobs_cancel`

*acts*

Kill a job's whole process tree (quartus_fit, vsimk, mame).

| Argument | Type | Default |
|---|---|---|
| `job` | string | required |

### `locks_status`

*read-only*

JTAG marker, queued JTAG sessions, running Quartus/ModelSim processes, active jobs.

## Builds

### `build_start`

*acts*

| Argument | Type | Default |
|---|---|---|
| `core` | string | required |
| `rev` | string | `""` |
| `seed` | integer or null | `null` |
| `allow_dirty` | boolean | `false` |
| `wait_s` | integer | `5` |

### `build_report`

*read-only*

The last build's commit, setup/hold slack and TNS per clock, fit resources, .rbf path.

| Argument | Type | Default |
|---|---|---|
| `core` | string | required |
| `rev` | string | `""` |

### `build_worst_paths`

*acts*

quartus_sta with scripts/report_worst_paths.tcl on the compiled database (no recompile). Writes output_files/worst_paths_<rev>.rpt.

| Argument | Type | Default |
|---|---|---|
| `core` | string | required |
| `rev` | string | `""` |
| `wait_s` | integer | `300` |

### `build_floorplan`

*acts*

| Argument | Type | Default |
|---|---|---|
| `core` | string | required |

## Simulation

### `sim_list`

*read-only*

Testbenches under sim/, with which simulators each has a file list for.

| Argument | Type | Default |

### `sim_run`

*acts*

One testbench: scripts/run_sim.sh (ModelSim; fresh library, one at a time per core) or scripts/run_verilator.sh. `args` go through (+plusargs, -Gparam=, --threads=N). The result flags $readmem warnings, which mean empty ROMs rather than an RTL fault.

| Argument | Type | Default |
|---|---|---|
| `core` | string | required |
| `bench` | string | required |
| `simulator` | string | `"modelsim"` |
| `args` | list[string] or null | `null` |
| `wait_s` | integer | `120` |

### `sim_compare_boot`

*acts*

scripts/compare_boot_trace.py replay|compare <set>: the RTL's boot against MAME's trace.

| Argument | Type | Default |
|---|---|---|
| `core` | string | required |
| `set` | string | required |
| `cmd` | string | `"compare"` |
| `wait_s` | integer | `300` |

### `sim_sweep`

*acts*

Orphaned vsim/vsimk processes (no running sim job) and stale work/_lock files. kill=True ends the processes and removes the locks.

| Argument | Type | Default |
|---|---|---|
| `kill` | boolean | `false` |

## MAME
